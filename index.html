Tools Wajib
untuk TKJ

📦
Cisco Packet Tracer
Simulasi jaringan Cisco. Ideal untuk belajar routing, switching, dan VLAN tanpa perangkat fisik.
Gratis untuk pelajar
🖥️
VirtualBox
Virtual machine untuk menjalankan Linux, Windows Server, atau sistem operasi lain untuk lab praktik.
Open Source
🔍
Wireshark
Packet analyzer untuk memonitor dan menganalisis lalu lintas jaringan secara real-time.
Gratis
🌐
WinBox (MikroTik)
GUI untuk konfigurasi router MikroTik. Mudah digunakan untuk manajemen jaringan.
Gratis
🔒
Kali Linux
Distro Linux untuk pentesting dan keamanan jaringan. Tersedia ratusan tools security.
Open Source
📡
GNS3
Network emulator untuk simulasi jaringan kompleks dengan perangkat nyata secara virtual.
Gratis
💻
PuTTY
SSH dan Telnet client untuk akses remote ke server Linux atau perangkat jaringan.
Gratis
📊
Nmap
Network scanner untuk discovery host, port scanning, dan deteksi OS dan service.
Open Source
